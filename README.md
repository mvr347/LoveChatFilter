# LoveChatFilter

Продвинутый модульный фильтр чата v3.0 с поддержкой фильтрации рекламы, мата, капса, спама и кастомных правил.

## Общая структура

LoveChatFilter интегрируется с LoveChat и предоставляет многоуровневую фильтрацию сообщений игроков:

- **Реклама** — детектирует IP-адреса, доменные имена, ссылки
- **Мат** — фильтрует запрещённые слова (настраивается в конфиге)
- **Капс** — ограничивает количество заглавных букв
- **Спам** — отслеживает частоту сообщений (flood detection)
- **Кастомные правила** — регулярные выражения (regex) для специальных случаев

Все события фильтрации (срабатывания, обходы) логируются в SQLite базу данных для аудита.

## Команды

| Команда | Алиасы | Описание | Пермишин |
|---|---|---|---|
| `/lcf` | `lovechatfilter` | Главная команда фильтра (перезагрузка, статистика) | `lovechatfilter.reload` |

### Подкоманды `/lcf`

- `reload` — перезагрузить config.yml и rules.yml
- `stats` — показать статистику срабатываний по типам
- `clear <type>` — очистить логи определённого типа фильтра
- `test <сообщение>` — протестировать сообщение против фильтра (без отправки)

## Пермишины

| Пермишин | Описание | Default |
|---|---|---|
| `lovechatfilter.reload` | Право перезагружать конфиг и статистику | op |
| `lovechatfilter.bypass.ads` | Обход фильтра рекламы | op |
| `lovechatfilter.bypass.badwords` | Обход фильтра мата | op |
| `lovechatfilter.bypass.caps` | Обход фильтра капса | op |
| `lovechatfilter.bypass.spam` | Обход фильтра спама | op |

## Конфигурация (`config.yml`)

### Основные параметры

```yaml
plugin:
  enabled: true
  debug: false

# Реклама
ads:
  enabled: true
  # Детектирует IPv4/IPv6, домены, ссылки
  detect-ipv4: true
  detect-ipv6: true
  detect-domains: true
  detect-urls: true
  # Белый список доменов, которые можно упоминать
  whitelist:
    - "example.com"
    - "official-site.ru"
  action: "WARN"                    # WARN | KICK | MUTE | CUSTOM_COMMAND

# Мат
badwords:
  enabled: true
  case-insensitive: true
  # Слова загружаются из отдельного файла badwords.txt
  check-usernames: false            # проверять ники игроков
  action: "CENSORE"                 # CENSORE | WARN | KICK | MUTE

# Капс (заглавные буквы)
caps:
  enabled: true
  max-percent: 30                   # максимум % заглавных букв в сообщении
  min-message-length: 5             # минимум символов в сообщении (игнорируются короткие)
  action: "LOWERCASE"               # LOWERCASE | WARN | KICK

# Спам
spam:
  enabled: true
  max-messages-per-minute: 10       # максимум сообщений в минуту
  duplicate-check: true             # блокировать одинаковые сообщения подряд
  cooldown-seconds: 1               # минимум секунд между сообщениями
  action: "MUTE"                    # MUTE | WARN | KICK

# Логирование
logging:
  enabled: true
  log-all-messages: false           # логировать ВСЕ сообщения (требует много места)
  log-filtered-only: true           # логировать только срабатывания
  keep-history-days: 30             # сколько дней хранить логи

# База данных
database:
  file: "chatfilter.db"
  pool-size: 10
```

## Кастомные правила (`rules.yml`)

```yaml
custom_rules:
  spam_pattern_1:
    enabled: true
    pattern: "(?i)(\\b[a-z0-9]{1,3}\\b){5,}"  # повторяющиеся короткие слова
    action: "MUTE"
    duration-minutes: 5              # если действие = MUTE
    reason: "Detected spam pattern"

  advertisement_urls:
    enabled: true
    pattern: "(?i)\\b(twitch|discord|youtube)\\.com\\b"
    action: "KICK"
    reason: "External service advertisement not allowed"
```

## Действия фильтра

- **WARN** — выдать игроку предупреждение в приватном сообщении
- **CENSORE** — заменить запрещённые слова на `****`
- **LOWERCASE** — конвертировать сообщение в нижний регистр
- **MUTE** — принудительно замутировать игрока на время
- **KICK** — выкинуть игрока с сервера с причиной
- **CUSTOM_COMMAND** — выполнить кастомную команду (например, `lp user {player} group set muted`)

## Интеграции

### LoveChat

LoveChatFilter расширяет LoveChat, обрабатывая каждое сообщение перед тем, как оно попадёт в основной чат.

### PlaceholderAPI

Плейсхолдеры для отображения статистики фильтра в профилях игроков.

## Механика фильтрации

1. **Событие чата** → игрок пишет в чат
2. **Проверка пермишинов** → если у игрока есть пермишин `bypass.X`, фильтр пропускается для этого типа
3. **Поэтапная проверка** → сообщение проверяется по очереди против всех активных фильтров
4. **Действие** → при срабатывании применяется соответствующее действие (warn, kick, mute, etc.)
5. **Логирование** → событие фиксируется в БД для аудита

## Структура данных

- `filter_events` — все срабатывания фильтра (время, игрок, тип фильтра, сообщение, действие)
- `spam_tracker` — отслеживание спама по игроку (последние сообщения, time windows)
- `muted_players` — активные муты (игрок, срок истечения, причина)
- `filter_stats` — статистика по типам срабатываний (для `/lcf stats`)

## Лучшие практики

1. **Белый список доменов** — добавить официальные ссылки сервера в `ads.whitelist`
2. **Кастомные правила** — использовать regex для специальных случаев (пример выше)
3. **Пермишины** — дать `bypass.*` только модераторам/администраторам
4. **Логирование** — включить для аудита, но отключить логирование всех сообщений (экономия места)
